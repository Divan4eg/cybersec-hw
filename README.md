### Задание 2
Проведите сканирование Metasploitable в режимах SYN, FIN, Xmas, UDP.

Запишите сеансы сканирования в Wireshark.

Ответьте на следующие вопросы:

- Чем отличаются эти режимы сканирования с точки зрения сетевого трафика?
- Как отвечает сервер?
Приведите ответ в свободной форме.

### Решение 2

1. SYN-сканирование (-sS)
- Отправляет SYN-пакет
- Если порт открыт — получает SYN-ACK
- Отправляет RST для закрытия соединения

2. FIN-сканирование (-sF)
- Отправляет FIN-пакет
- Открытые порты игнорируют пакет
- Закрытые порты отвечают RST

3. Xmas-сканирование (-sX)
- Отправляет пакет с флагами FIN, PSH и URG
- Открытые порты игнорируют пакет
- Закрытые порты отвечают RST

4. UDP-сканирование (-sU)
- Отправляет пустые UDP-пакеты
- Закрытые порты отвечают ICMP “порт недоступен”
- Открытые порты не отвечают
